# 蒙自城镇供水 (Mengzi Water)

Home Assistant 自定义集成,用于查询**蒙自市城镇供水有限责任公司**网上营业厅的户号数据:预存金额、待缴欠费、缴费时间、供水状态等。

> ⚠️ **非官方集成**。只读查询,不做缴费/转账。数据通过网上营业厅 H5 接口获取,接口可能随时调整;会话 Cookie 仅保存在本机 HA 配置中,不会上传到任何第三方。

## 功能特性

- 读取全部**已绑定户号**(微信营业厅内绑定的户号,一个集成同时管理)
- 每个户号:**预存金额 / 待缴欠费合计 / 待缴账单数 / 最近缴费时间 / 供水状态**
- **按“实际使用月”归集**(月头抄表,本期账单实为上期用量;抄表日≤15 日 → 实际使用月=抄表月-1):本月/本季/本年用水量(m³)与水费(元),附最近账单抄表日、表码、折合单价等属性
- **费用分解独立实体**:自来水费、污水处理费、垃圾处理费(10 元/户/月定额)、违约金(滞纳金)—— 本季与本年各 4 个;最近一期账单 4 个分解实体
- **阶梯/定价**:自动拉取营业厅《水价公示》并解析价目表(居民一档≤15m³ 到户4.40、二档16-25m³ 6.00、三档≥26m³ 7.50;非居民 5.90、特种 10.00),最近账单的“适用阶梯”在属性中给出
- 户号/户名/用址/册名/用水类型/水表数/抄表员/最近更新为**普通可见实体**
- 轮询间隔可配置(默认 30 分钟);会话失效自动提示重新认证

> 账单规则(实测):每月 1~4 日月头抄表;账期=抄表月,缴费在抄表当月完成,用量实际为上一自然月。

## 安装

### HACS(推荐)

1. HACS → 右上角 `⋯` → **自定义存储库 (Custom repositories)**
2. 存储库地址填 `https://github.com/ly2199/ha_mengzi_water`,类别选 **集成 (Integration)** → 添加
3. 搜索 **蒙自城镇供水 (Mengzi Water)** → 下载 → 重启 Home Assistant

### 手动安装

将 `custom_components/mengzi_water/` 整个文件夹复制到 HA 配置目录的 `custom_components/mengzi_water/` 下,重启。

## 配置(获取会话 Cookie)

本系统登录依赖微信网页授权,HA 无法自主登录,需要一次性抓取会话 Cookie:

1. 手机微信打开 `https://swp.mzczgs.com/Hall/`,完成授权登录并确认能看到户号数据
2. 手机设置代理指向电脑上的抓包工具(**mitmproxy / Charles** 等),回到微信重新打开一次营业厅首页
3. 在抓包工具中找到发往 `swp.mzczgs.com` 的任意 POST 请求,复制请求头 **Cookie** 中 `Ares.Core.Session.JXSWPHALL=...` 的值(整段 `名=值` 粘贴即可,容忍整段 Cookie)
4. HA:设置 → 设备与服务 → 添加集成 → **蒙自城镇供水** → 粘贴 Cookie → 提交(向导会实时校验并回显户号信息)
5. **可选:填写 openId 实现自动续期**(微信 openId 长期有效,建议填写):在微信抓包中找到 `Fun=HallEx.Login` 的请求,其 Params 第一个参数值即为 openId;填入后,Cookie 过期时集成会自动重新登录换取新会话,无需再手动抓包。也可稍后在“重新认证”中补充。

之后集成按设定间隔自动轮询;数据仅保存在本机 HA 的配置条目中(与其他凭据同等加密存放)。

## 会话自动续期机制

- **Set-Cookie 轮换吸收**:若服务端在任意响应中回发新的会话 Cookie,集成会自动吸收并写入配置(滑动续期)
- **openId 自动重登**(需在配置中填写 openId):检测到会话失效后自动调用登录接口换新会话并重试拉取,全程无需人工干预;若未配置 openId,仍会提示“需要重新认证”
- 服务端偶发的瞬时“会话失效”误报会先自动重试 3 次,不会误触发重新认证

## 会话失效怎么办

- 集成会显示“需要重新认证”错误,进入 设备与服务 → 该集成 → 重新认证
- 重新按上述步骤抓一次最新 Cookie 粘贴即可;老 Cookie 有效期取决于供水公司服务端(实测随会话而定),无需频繁更新

## 传感器(每户号 33 个 + 集成级 1 个)

**基础**:预存金额、待缴欠费合计、待缴账单数、最近缴费时间、供水状态

**用量/费用(实际使用月口径,自然月/季/年)**:本月/本季/本年实际用水量、本月/本季/本年实际水费

**费用分解(本季/本年 × 4)**:自来水费、污水处理费、垃圾处理费(定额10元/月)、违约金

**最近一期账单**:用水量、费用合计、自来水费、污水处理费、垃圾处理费、违约金(附:抄表日/表码/折合单价/适用阶梯/费用分解)

**户号信息**:户号、户名、用址、册名、用水类型、水表数、抄表员、最近更新

**集成级**:水价标准(状态=公示标题;属性含结构化价目表与公示原文)

> 实体 ID 形如 `sensor.mengzi_water_<户号>_usage_year`,多户号互不干扰。
